# 7. Glosario

| Término | Significado |
| --- | --- |
| Administrador (Admin) | Perfil con acceso completo al sistema |
| Anular | Dejar sin efecto un recibo o egreso, con un motivo. No se borra: queda marcado como anulado |
| Auxiliar | Perfil para meseros, cocina y caja, con acceso limitado |
| Cierre de caja | Registro diario que compara el efectivo esperado con el contado |
| Comanda | Cada plato que llega a la cocina para prepararse |
| Comprobante de egreso | Documento que registra una salida de dinero |
| Consumidor final | Cliente genérico para las ventas en que el cliente no da sus datos |
| Estado | Situación de un registro: Creado, En preparación, Finalizado, Disponible, Pendiente, etc. |
| Forma de pago | Medio con que se paga: efectivo o transferencia |
| Inactivar | Dejar de usar un registro sin borrarlo |
| Materia prima (insumo) | Producto que se compra para preparar los platos |
| Modo consulta | Pantalla que el perfil puede ver pero no modificar |
| MySQL / XAMPP | Programas donde se guarda la base de datos del sistema |
| Pedido | Lo que pide una mesa. Puede estar Creado (abierto), Finalizado o Cancelado |
| PQRS | Peticiones, Quejas, Reclamos y Sugerencias de los clientes |
| Radicado | Número que identifica una PQRS para consultarla después |
| Recibo de caja | Documento que registra el cobro de un pedido |
| Sesión | Periodo en que un usuario está dentro del sistema |
| Stock mínimo | Cantidad mínima de una materia prima antes de tener que reponerla |
| Tercero | Persona o empresa a la que se le paga un egreso |
