# Glosario técnico

| Término       | Definición                                                                          |
| ------------- | ----------------------------------------------------------------------------------- |
| API           | Interfaz que permite que dos componentes de software se comuniquen.                 |
| API REST      | Estilo de servicios web que utiliza recursos y métodos HTTP.                        |
| Backend       | Componente del sistema que procesa solicitudes y aplica la lógica de la aplicación. |
| Base de datos | Sistema organizado para almacenar y consultar información.                          |
| DAO           | Objeto de acceso a datos; encapsula las operaciones de persistencia.                |
| Endpoint      | Ruta de una API a la que se envía una solicitud.                                    |
| Frontend      | Interfaz con la que interactúa el usuario.                                          |
| HTTP          | Protocolo utilizado para la comunicación entre cliente y servidor.                  |
| JSON          | Formato de intercambio de datos basado en pares clave-valor.                        |
| JDBC          | Tecnología de Java para conectarse y ejecutar operaciones en bases de datos.        |
| JdbcTemplate  | Componente de Spring JDBC que simplifica la ejecución de consultas SQL.             |
| Modelo        | Clase que representa datos del dominio de la aplicación.                            |
| MySQL         | Sistema de gestión de bases de datos relacional.                                    |
| Spring Boot   | Framework de Java utilizado para construir aplicaciones Spring.                     |
| Spring Web    | Módulo de Spring para desarrollar aplicaciones y servicios web.                     |
