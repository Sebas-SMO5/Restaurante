# Tester - Sistema de Gestión de Restaurante

## Rol - Maria Gutierrez (Tester)
Responsable de testing y validación del sistema de gestión de restaurante.

## Objetivo
Verificar el correcto funcionamiento de las funcionalidades del sistema, validar los resultados obtenidos e identificar posibles errores.

## Alcance
- Validación de funcionalidades.
- Verificación de formularios.
- Validación de datos de entrada.
- Consultas y registros.
- Verificación de respuestas del sistema.
- Persistencia de información.
- Integración entre frontend, backend y base de datos.

## Herramientas
- JUnit
- Spring Boot Test
- Maven
- Postman
- MySQL
- Navegador web
- Git y GitHub

## Tipos de pruebas
- Pruebas funcionales.
- Pruebas manuales.
- Pruebas de validación.
- Pruebas de integración.
- Pruebas automatizadas.

## Responsabilidades
- Definir escenarios de prueba.
- Ejecutar pruebas.
- Comparar resultados esperados y obtenidos.
- Identificar y documentar errores.
- Verificar correcciones.
- Validar el comportamiento general del sistema.
